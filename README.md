# ai-untell

**AI yazım izlerini tespit et, temizle ve gerekirse LLM ile "insansılaştır".**

`ai-untell`, Claude/ChatGPT/Gemini gibi modellerin ürettiği metin ve kodlardaki
görünür AI izlerini (em-dash aşırı kullanımı, AI kelime dağarcığı, chatbot
açılış/kapanış kalıpları, çift tire, görünmez Unicode karakterler, homoglyph'ler)
tespit edip temizleyen bir Python aracıdır. Tamamen **çevrimdışı ve kural
tabanlı** çalışır; isterseniz API anahtarı ile LLM paraphrase katmanını
açarak istatistiksel watermark'ları da bozabilirsiniz ("jamming").

> Araştırma özeti için [RESEARCH.md](RESEARCH.md), uygulama planı için
> [implementation_plan.md](implementation_plan.md) dosyalarına bakın.

## Ne yapar?

| Katman | Ne işe yarar | Gereksinim |
|---|---|---|
| **scan** | 15 kategoride AI izi tespit eder, 0–1 arası skor üretir | Yok (offline) |
| **clean** | Tespit edilen izleri deterministik kurallarla temizler | Yok (offline) |
| **humanize** | LLM ile doğal dille yeniden yazar (fallback: clean) | Opsiyonel API key |

Temizlenen izler:

- Em-dash (`—`) ve çift tire (`--`) aşırı kullanımı
- AI kelime dağarcığı: *delve, leverage, utilize, foster, seamless, robust,
  holistic, multifaceted, tapestry, realm, pivotal, crucial, testament,
  moreover, furthermore, in conclusion, game-changer, cutting-edge...*
- Copula kaçınması: *serves as, stands as, functions as* → *is*
- Negatif paralelizm: *not only X but also Y* → *X and Y*
- Chatbot açılışları (*Certainly!*, *Here's a comprehensive overview...*)
  ve kapanışları (*Let me know if you have any questions!*)
- Bilgi kesintisi açıklamaları (*As an AI language model...*)
- Görünmez Unicode: zero-width space, soft hyphen, tag karakterleri
  (U+E0000–E007F), bidi kontrolleri (emoji ZWJ dizileri korunur)
- Homoglyph'ler: Kiril/Grek harfleri → Latin eşdeğerleri
- Kod içinde: `# Generated by Claude` satırları, yorum/docstring içindeki izler
  (**identifier'lar ve sözdizimi asla değişmez**)

## Kurulum

```bash
cd ai-untell
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"        # geliştirme + testler
.venv/bin/pip install -e ".[llm]"        # Anthropic/OpenAI humanizer için
```

## CLI kullanımı

```bash
# Tarama: skor + kategori raporu
ai-untell scan belge.md
ai-untell scan belge.md --json -v
ai-untell scan --text "Let's delve into this — it's a game-changer."

# Temizleme (stdout'a yazar; pipe için idealdir)
ai-untell clean belge.md
ai-untell clean belge.md --in-place                 # .bak yedeği ile
ai-untell clean belge.md --in-place --no-backup
ai-untell clean kod.py --strength moderate          # light|moderate|aggressive
ai-untell clean belge.md --em-dash period --double-dash remove
cat belge.md | ai-untell clean > temiz.md           # stdin/stdout

# İnsansılaştırma (API key varsa LLM, yoksa kural fallback)
ai-untell humanize belge.md                          # offline fallback
ai-untell humanize belge.md --llm --provider anthropic
ai-untell humanize belge.md --llm --provider openai --model gpt-4o-mini
ai-untell humanize belge.md --llm --provider ollama --model llama3.1
ai-untell humanize belge.md --llm --in-place

# Demo
ai-untell demo
```

## Python API

```python
from ai_untell import scan, clean, humanize, scan_file, clean_file, Config

report = scan("Coffee is not just a beverage — it's a journey.")
print(report.ai_score)          # ör. 0.62
print(report.per_category)      # {TellCategory.DASH_OVERUSE: 1, ...}

result = clean("Let's delve into it — it serves as a testament.")
print(result.cleaned)           # "Let's dig into it, it is a testament..."
print(result.diff_stats)        # {'em_dash_replaced': 1, 'replaced_ai_vocab': 2, ...}

# Dosya üzerinde
report = scan_file("notlar.md")
clean_file("notlar.md", in_place=True)   # notlar.md.bak yedeği oluşturur

# Agresif mod + emoji silme
cfg = Config(synonym_strength="aggressive", strip_emoji=True)
result = clean("Bu araç gerçekten seamless 🚀 ve robust.", config=cfg)
```

## Kod temizleme garantileri

- Dosya türü otomatik algılanır (Python, JS/TS, Go, Rust, Java, C#, C/C++,
  Markdown, karışık).
- Kodda yalnızca **yorumlar, docstring'ler ve string literal'leri** temizlenir;
  identifier, anahtar kelime ve sözdizimine dokunulmaz.
- Markdown'da fenced code block ve inline code (`...`) bölgeleri korunur.
- `preserve_code_strings=True` ile string literal'leri de koruyabilirsiniz.

## Skorlama

Her kategorinin bir ağırlığı ve doygunluk eşiği (100 token başına hit) vardır.
Skor = ağırlıklı, 0–1 aralığında normalize toplam:

- `>= 0.5` → LIKELY AI
- `< 0.5` → LOW AI SIGNAL

Demo metinde: temizlik öncesi **0.551** → temizlik sonrası **0.170**.

## Sınırlamalar ve dürüst notlar

- **Token-düzey istatistiksel watermark'lar** (Kirchenbauer green-list,
  Aaronson Gumbel) model/anahtar erişimi olmadan *tespit edilemez*; `clean`
  bunları kaldırdığını iddia etmez. Bu watermark'ları bozmanın literatürdeki
  yolu paraphrase saldırısıdır ve bunu `humanize --llm` yapar.
- Anthropic'in Claude çıktısına production watermark uyguladığına dair
  kamuya açık bir kanıt (bu araştırma tarihi itibarıyla) yoktur.
- AI tespit sistemlerini atlatma garantisi verilmez; kural tabanlı temizlik
  görünür izleri kaldırır, classifier tabanlı detektörler için LLM katmanı
  önerilir.
- Homoglyph normalizasyonu yalnızca Latin ağırlıklı belgelerde uygulanır
  (gerçek Kiril/Grek metinler bozulmaz).
