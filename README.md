# ai-untell

[![CI](https://github.com/myaslioglu/ai-untell/actions/workflows/ci.yml/badge.svg)](https://github.com/myaslioglu/ai-untell/actions/workflows/ci.yml)

**AI yazım izlerini tespit et, temizle ve gerekirse "insansılaştır".**

`ai-untell`, Claude, ChatGPT, Gemini gibi modellerin ürettiği metin ve
kodlardaki görünür AI izlerini bulur ve temizler: em dash aşırı kullanımı, AI
kelime dağarcığı, chatbot açılış/kapanış kalıpları, çift tire, görünmez
Unicode karakterler, homoglyph'ler. Tamamen **çevrimdışı ve kural tabanlı**
çalışır. İki şekilde kullanılabilir:

1. **Claude skill / plugin olarak**: Claude Code'da (yerel ve bulut), claude.ai
   sohbetinde ve Claude API'de. Bağımlılık yok, sadece `python3` yeterli.
   Kurulum için [en alttaki bölüme](#claudea-ekleme) bakın.
2. **Python paketi ve CLI olarak**: `pip install -e .` ile `ai-untell` komutu.

> Araştırma özeti için [RESEARCH.md](RESEARCH.md), uygulama planı için
> [implementation_plan.md](implementation_plan.md) dosyalarına bakın.

## Ne yapar?

| Komut | Ne işe yarar | Gereksinim |
|---|---|---|
| **scan** | 15 kategoride AI izi tespit eder, 0 ile 1 arası skor üretir | Yok (offline) |
| **clean** | Tespit edilen izleri deterministik kurallarla temizler | Yok (offline) |
| **humanize** | Metni baştan yeniden yazar (Claude skill'inde Claude'un kendisi, CLI'da LLM API) | Skill'de yok; CLI'da API anahtarı |

Temizlenen izler:

- Em dash (`—`, boşluklu ya da bitişik) ve yazı içinde tire yerine kullanılan çift tire (`--`)
- AI kelime dağarcığı: *delve, leverage, utilize, foster, seamless, robust,
  holistic, multifaceted, tapestry, realm, pivotal, crucial, testament,
  moreover, furthermore, in conclusion, game-changer, cutting-edge...*
- Copula kaçınması: *serves as, stands as, functions as* → *is*
- Negatif paralelizm: *not only X but also Y* → *X and Y*
- Chatbot açılışları (*Certainly!*, *Here's a comprehensive overview...*)
  ve kapanışları (*Let me know if you have any questions!*)
- Yapay zekânın kendini tanıttığı cümleler (*As an AI language model...*)
- Görünmez Unicode: zero-width space, soft hyphen, tag karakterleri
  (U+E0000 ile E007F arası), bidi kontrolleri (emoji ZWJ dizileri korunur)
- Homoglyph'ler: Kiril/Grek harfleri → Latin eşdeğerleri
- Kodda: `# Generated by Claude` satırları, yorum ve docstring içindeki izler

### İnsan yazısına dokunmaz

Bir temizleyicinin asıl riski, AI izini kaçırmak değil, insan yazısını
bozmaktır. Bu yüzden şunlar bilerek korunur (hepsi
[`tests/test_regressions.py`](tests/test_regressions.py) içinde test edilir):

- Koddaki **string literal'ler** (`"--in-place"`, regex'ler, sözlük anahtarları,
  SQL). İstenirse `--clean-strings` ile açılır.
- Komut satırı bayrakları (`--help`) ve Markdown tablo ayraçları (`|--|--|`)
- Kapanmamış ` ``` ` blokları dahil tüm kod blokları
- "Surely", "Of course the server..." gibi sıradan cümle başları
- Teknik yazıdaki "language model" geçen cümleler
- Markdown satır sonu için bırakılan iki boşluk

## Python paketi olarak kurulum

```bash
git clone https://github.com/myaslioglu/ai-untell.git
cd ai-untell
make setup            # .venv + pip install -e ".[all]"
```

Elle kurmak isterseniz:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e ".[dev]"   # geliştirme + testler
.venv/bin/python -m pip install -e ".[llm]"   # Anthropic/OpenAI humanizer için
```

## CLI kullanımı

```bash
# Tarama: skor + kategori raporu
ai-untell scan belge.md
ai-untell scan belge.md --json -v
ai-untell scan --text "Let's delve into this — it's a game-changer."

# Temizleme (stdout'a yazar, pipe için uygun)
ai-untell clean belge.md
ai-untell clean belge.md --in-place                 # .bak yedeği ile
ai-untell clean belge.md --in-place --no-backup
ai-untell clean kod.py --strength moderate          # off|light|moderate|aggressive
ai-untell clean belge.md --em-dash period --double-dash remove
ai-untell clean kod.py --clean-strings              # string literal'leri de temizle
cat belge.md | ai-untell clean - > temiz.md         # stdin/stdout

# İnsansılaştırma (LLM ile yeniden yazım)
ai-untell humanize belge.md                          # --llm olmadan: clean ile aynı
ai-untell humanize belge.md --llm --provider anthropic
ai-untell humanize belge.md --llm --provider openai --model gpt-4o-mini
ai-untell humanize belge.md --llm --provider ollama --model llama3.1
ai-untell humanize belge.md --llm --in-place
ai-untell humanize belge.md --llm --fallback         # LLM hata verirse kural tabanlı temizliğe düş

# Demo
ai-untell demo
```

`--em-dash` seçenekleri: `auto`/`comma` virgüle çevirir, `period` cümleyi
böler ve sonraki kelimeyi büyük harfle başlatır, `parens` iki tire arasındaki
ara sözü paranteze alır, `strip` siler, `keep` dokunmaz.

`humanize --llm` başarısız olursa (paket yok, API anahtarı yok, ağ hatası,
model çıktı sınırına takıldı) **açık bir hata verir ve dosyaya hiçbir şey
yazmaz**. Sessizce kural tabanlı moda düşmesi için `--fallback` verin. Çıktı
token bütçesi girdinin uzunluğuna göre ayarlanır; model yine de sınıra
takılırsa yarım kalmış metin asla kabul edilmez.

## Python API

```python
from ai_untell import scan, clean, humanize, scan_file, clean_file, Config

report = scan("Coffee is not just a beverage — it's a journey.")
print(report.ai_score)
print(report.per_category)      # {TellCategory.DASH_OVERUSE: 1, ...}

result = clean("Let's delve into it — it serves as a testament.")
print(result.cleaned)           # "Let's dig into it, it is a testament."
print(result.diff_stats)        # {'em_dash_replaced': 1, 'replaced_ai_vocab': 2, ...}

# Dosya üzerinde
report = scan_file("notlar.md")
clean_file("notlar.md", in_place=True)   # notlar.md.bak yedeği oluşturur

# Agresif mod + emoji silme
cfg = Config(synonym_strength="aggressive", strip_emoji=True)
result = clean("Bu araç gerçekten seamless 🚀 ve robust.", config=cfg)

# LLM ile, hata olursa kural tabanlı temizliğe düşerek
cfg = Config(use_llm=True, llm_provider="anthropic", llm_fallback=True)
result = humanize(open("taslak.md").read(), config=cfg)
print(result.mode)              # "llm" ya da "rules"
```

## Skorlama

Her kategorinin bir ağırlığı ve bir doygunluk eşiği (100 token başına isabet)
vardır. Skor, bunların ağırlıklı ve 0 ile 1 arasına normalize edilmiş
toplamıdır:

- `>= 0.5` → LIKELY AI
- `< 0.5` → LOW AI SIGNAL

Demo metinde skor temizlik öncesi **0.486**, temizlik sonrası **0.234**.

## Sınırlamalar

- **Token düzeyindeki istatistiksel watermark'lar** (Kirchenbauer green-list,
  Aaronson Gumbel) model ya da anahtar erişimi olmadan tespit edilemez.
  `clean` bunları kaldırdığını iddia etmez. Literatürde bu watermark'ları
  bozmanın yolu metni başka bir modelle yeniden yazmaktır. Claude skill'i
  bunu Claude'a yaptırır; CLI'da `humanize --llm` aynı işi görür.
- Anthropic'in Claude çıktısına production watermark uyguladığına dair kamuya
  açık bir kanıt (bu araştırma tarihi itibarıyla) yoktur.
- AI tespit sistemlerini atlatma garantisi verilmez. Kural tabanlı temizlik
  görünür izleri kaldırır; classifier tabanlı detektörler için yeniden yazım
  önerilir.
- Homoglyph normalizasyonu yalnızca Latin ağırlıklı belgelerde uygulanır,
  gerçek Kiril/Grek metinler bozulmaz.

### Ortam değişkenleri

- `ANTHROPIC_API_KEY`: `--provider anthropic` için
- `OPENAI_API_KEY`: `--provider openai` için
- Ollama için anahtar gerekmez (`http://localhost:11434` varsayılır)

## Claude'a ekleme

Skill, `skills/ai-untell/` klasöründeki tek bir paket olarak gelir ve her
ortamda aynı şekilde çalışır. Kurduktan sonra Claude'a doğal dille sormanız
yeterli: *"bu metin AI gibi duruyor mu?"*, *"README'deki em dash'leri
temizle"*, *"bunu insansılaştır"*. Skill otomatik devreye girer.

### 1. Claude Code (terminal, masaüstü uygulaması, IDE)

Plugin olarak kurun. Güncellemeleri de bu yolla alırsınız. Claude Code
içinde:

```
/plugin marketplace add myaslioglu/ai-untell
/plugin install ai-untell@ai-untell
```

Skill `ai-untell:ai-untell` adıyla görünür; isterseniz doğrudan
`/ai-untell:ai-untell` ile çağırabilirsiniz. Güncellemek için
`/plugin marketplace update ai-untell` yeterli.

Plugin kullanmak istemezseniz kişisel skill olarak da kopyalayabilirsiniz:

```bash
git clone https://github.com/myaslioglu/ai-untell.git
cd ai-untell && make install-skill     # ~/.claude/skills/ai-untell
```

İkisini birden kurmayın, yoksa skill iki kez listelenir.

### 2. Claude Code bulut oturumları (claude.ai/code, masaüstündeki Cloud ortamı)

Bulut oturumları bilgisayarınızdaki `~/.claude/skills` klasörünü görmez;
yalnızca üzerinde çalıştıkları reponun ayarlarını yükler. Skill'i kullanmak
istediğiniz her reponun `.claude/settings.json` dosyasına şunu ekleyip commit
edin:

```json
{
  "extraKnownMarketplaces": {
    "ai-untell": {
      "source": { "source": "github", "repo": "myaslioglu/ai-untell" }
    }
  },
  "enabledPlugins": {
    "ai-untell@ai-untell": true
  }
}
```

Bu repoda bu ayar zaten var, yani `ai-untell` reposunda açtığınız bulut
oturumlarında skill hazır gelir. Varsayılan ağ izinleri GitHub'a erişime
izin verir; ortamınızın ağ erişimini "None" yaptıysanız plugin
indirilemez. O durumda `skills/ai-untell` klasörünü o reponun
`.claude/skills/ai-untell` yoluna kopyalamak da işe yarar.

### 3. claude.ai sohbeti (web, masaüstü, mobil)

1. Zip'i üretin:
   ```bash
   make skill-zip      # dist/ai-untell-skill.zip
   ```
2. claude.ai'da **Settings → Capabilities** altında **Code execution**'ı açın.
3. **Customize → Skills** (eski arayüzde Settings → Capabilities → Skills)
   altında **Upload skill** ile `ai-untell-skill.zip` dosyasını yükleyin ve
   etkinleştirin.

claude.ai'ın sandbox'ında genellikle dış ağa erişim olmadığından
`humanize --llm` orada çalışmaz. Buna gerek de yok: skill, yeniden yazımı
Claude'un kendisine yaptırır ve sonucu `scan` ile doğrular.

### 4. Claude API

Aynı zip'i [Skills API](https://docs.claude.com/en/docs/agents-and-tools/agent-skills)
ile (`POST /v1/skills`) yükleyip code execution aracıyla birlikte
kullanabilirsiniz. Skill yalnızca standart kütüphaneye ihtiyaç duyduğu için
ağsız sandbox'ta sorunsuz çalışır.
